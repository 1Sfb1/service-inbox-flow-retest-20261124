# Service inbox · starter

## Nederlands

Kies **Use this template → Create a new repository** om je eigen kopie te maken. De vier fictieve verzoeken staan in `cases.json`. Open de tweetalige opdracht in je ACE-sollicitantenportaal voor de eisen en beoordelingscriteria. De tijdslimiet is twee uur. Je kunt lokaal of in een eigen ontwikkelomgeving werken.

Vervang deze tekst door je overdracht. Beschrijf hoe we je werk starten, de automatische roltest draaien en de foutstaat oproepen. Noem de gebruikte hulpmiddelen en welke keuze je met meer tijd zou herzien.

Controleer je openbare repository in het sollicitantenportaal. Vergelijk de commit met jouw laatste push. Kies vervolgens **Inleveren** en bevestig.

## English

Choose **Use this template → Create a new repository** to make your own copy. `cases.json` contains four fictional service requests. Your ACE applicant portal has the full brief and scoring criteria. The time limit is two hours. Work locally or in a development environment of your choice.

Replace this text with your handover. Explain how to run your work, run the automated role test and reproduce a load failure. Mention the tools you used and a decision you would revisit with more time.

Run the portal check against your public repository and compare the commit with your latest push. Choose **Hand in** and confirm.
